# AGENT.md

Avant toute modification, lecture ou exécution liée au projet, l'agent doit lire et appliquer les instructions définies dans [`.github/instructions/workflow.instructions.md`](.github/instructions/workflow.instructions.md).

Ces instructions font autorité pour le workflow de développement, les conventions de branche, la compréhension du projet, les tests, les commits et l'ouverture de pull requests.
